📐 基本句型

S-P-O 结构

和中文一样是"主谓宾"。不同：印尼语现在时没有"是"动词，直接说"我老师"就是"我是老师"。

Saya makan nasi.
我吃饭
Saya adalah guru.
我是老师（adalah用于名词前）
Dia sedang kerja.
他正在工作
🔄 常用词缀

me- 主动动词前缀

表示"做某动作"，变体：men-, mem-, meng-, meny-。

baca→membaca 读
Saya membaca buku.
tulis→menulis 写
Dia menulis laporan.

ber- 状态 / ter- 意外/最 / di- 被动

kerja→bekerja
Ayah bekerja di kantor.
besar→terbesar 最大
Ini yang terbesar.
buka→dibuka 被打开
Pintu dibuka.

-an 名词 / pe- 人物

makan→makanan 食物
印尼 makanan enak!
ajar→pengajar 教师
Dia pengajar.
❌ 否定词 / ❓ 疑问词

三兄弟：Tidak 不 / Bukan 不是 / Belum 还没

Saya tidak mau. / Saya bukan bos. / Saya belum makan.
我不要 / 我不是老板 / 我还没吃

疑问词

Apa? 什么 Siapa? 谁 Di mana? 在哪 Ke mana? 去哪 Kapan? 何时 Berapa? 多少 Kenapa? 为什么 Bagaimana? 怎样
Apa ini? / Berapa ini? / Kenapa tidak datang?
这是什么？/ 多少钱？/ 为什么不来？
👤 所有格 / 🔗 Yang / ⏰ 时间 / 💪 情态

所有格

-ku 我的 -mu 你的 -nya 他/她的
buku+ku=bukuku / nama+mu=namamu
我的书 / 你的名字

Yang = 中文的"

Buku yang bagus / Saya mau yang merah
好的书 / 我要红色的

时间助词 / 情态动词

Saya sudah mandi. / Dia sedang tidur.
我洗过澡了 / 他在睡觉
Saya bisa / mau / harus pergi.
我能/想/必须走了
🤝 打招呼与社交▼
  • Salam：见面微笑着握手，要轻柔，然后右手触碰心口
  • 右手法则：递东西、接东西、握手、指物一律用右手
  • 对长辈/上司要说Bapak（先生）或Ibu（女士）
💼 职场文化▼
  • 层级观念强，对上级用敬称
  • Jam Karet（橡胶时间）：时间较灵活，但你最好准时
  • Gotong Royong：团队互相帮助
  • 拒绝时委婉："Nanti dulu ya"，不要追问
🍜 饮食/宗教▼
  • 用手抓饭吃（右手），不习惯说"Minta sendok"要勺子
  • Sambal每餐必备，不能吃辣说"Tidak pedas"
  • 大部分Halal清真，不带猪肉到办公室
  • 斋月白天不在同事面前吃喝
  • 不要摸别人的头（包括小孩），头视为神圣
  • 不用食指指人，用大拇指示意
🏠 生活贴士▼
  • Macet（堵车）是日常，Gojek/Grab摩托更快
  • 工作沟通用WhatsApp，不用微信
  • 热带气候，11-3月雨季随身带伞
  • 欧标两孔圆脚插头，带转换器
  • 说话委婉、保持微笑，讲究menjaga muka（留面子）
