📐 基本句型

印尼语句子结构：主语 + 谓语 + 宾语

同中文一样，印尼语也是 S-P-O 结构，非常容易上手。最大的不同是：印尼语 没有"是"动词（现在时），直接说"我老师"就是"我是老师"。

Saya makan nasi.
我 吃 饭
Saya adalah guru.
我 是 老师（adalah 用于名词前，相当于"是"）
Dia sedang kerja.
他/她 正在 工作
🔄 常用词缀 (Awalan)

me- 主动动词前缀

加在动词前，表示"做某动作"。me- 会根据首字母变成 men-, mem-, meng-, meny- 等形式。

baca → membaca 读
Saya membaca buku. → 我正在读书
tulis → menulis 写
Dia menulis laporan. → 他在写报告
cari → mencari 找
Saya mencari kantor. → 我在找办公室
buat → membuat 制作
Dia membuat kopi. → 他在泡咖啡

ber- 状态/进行前缀

表示处于某种状态或进行某活动，类似英文的 "be + doing"。

kerja (工作) → bekerja (在工作)
Ayah bekerja di kantor. → 爸爸在办公室工作
bicara (说话) → berbicara (在说话)
Dia berbicara bahasa Indonesia. → 他说印尼语
libur (放假) → berlibur (度假中)
Saya berlibur ke Bali. → 我去巴厘岛度假

ter- 意外 / 最

表示"意外地做了"或"最……"（最高级）。

jatuh (掉) → terjatuh (摔倒了)
Ponsel saya terjatuh. → 我手机摔了
besar (大) → terbesar (最大的)
Ini yang terbesar. → 这是最大的

di- 被动前缀

表示"被……"，用法像中文的"被"字句。

buka (开) → dibuka (被打开)
Pintu dibuka. → 门被打开了
buat (做) → dibuat (被制作)
Makanan dibuat ibu. → 食物是妈妈做的
baca (读) → dibaca (被读)
Buku ini dibaca banyak orang. → 这本书被很多人读

-an 名词后缀 / pe- 人物前缀

-an 加在动词后变名词。pe- 加在动词前表示"做……的人"。

makan (吃) → makanan (食物)
印尼 makanan enak! → 印尼食物很好吃！
minum (喝) → minuman (饮料)
Apa minuman-nya? → 饮料是什么？
ajar (教) → pengajar (教师)
Dia pengajar bahasa. → 他是语言老师
❌ 否定词

Tidak vs Bukan vs Belum

Tidak (不) → 否定动词和形容词

Saya tidak mau.
我 不 想
Ini tidak mahal.
这 不 贵

Bukan (不是) → 否定名词

Saya bukan manajer.
我 不是 经理
Ini bukan buku saya.
这 不是 我的书

Belum (还没) → 否定"还没发生"

Saya belum makan.
我 还没 吃
Dia belum datang.
他 还没 来

👤 所有格 (Posesif)

印尼语的所有格用后缀表示，直接贴在名词后面，非常简洁：

-ku 我的 -mu 你的 -nya 他/她/它的
buku + ku = bukuku
我的书
mobil + nya = mobilnya
他的车
nama + mu = namamu
你的名字

注意：-ku 也可以放在名词前：buku saya = 我的书（两种说法都行）

🔗 Yang 的用法

Yang ≈ 中文的"的"（定语从句标记），连接修饰语和名词，非常常用。

Buku yang bagus
好的书 / 好书
Orang yang berbicara
正在说话的人
Saya mau yang merah
我要那个红色的
Rumah yang besar itu
那间大的房子
⏰ 时间助词

Sudah (已经) vs Belum (还没)

Saya sudah mandi.
我已经洗澡了
Saya belum mandi.
我还没洗澡

Sedang (正在) vs Pernah (曾经) vs Akan (将要)

Dia sedang tidur.
他正在睡觉
Saya pernah ke Bali.
我去过巴厘岛
Saya akan pergi besok.
我明天将要走

🤝 打招呼与社交礼仪▼
  • 塞拉姆（Salam）：见面时微笑着握手，握手要轻柔（不是中式的用力握），然后用右手触碰自己心口，表示真诚。
  • 左右手：递东西、接东西、握手、指物 一律用右手，左手被认为不洁。
  • Apa Kabar 是万能开场：见到任何人都可以用，回答 "Baik, Anda?" 即可。
  • "Sudah Makan?"（吃了吗）也是常见的问候，不是真的想请你吃饭，就是寒暄。
  • 对长辈/上司要说 Bapak（先生） 或 Ibu（女士），不要直呼其名。
  • 印尼人普遍很爱笑，微笑是日常交流的润滑剂。
💼 职场文化▼
  • 层级观念较强：印尼职场尊重资历和职位，对上级要使用敬称（Bapak / Ibu），即使对方比你年轻。
  • Jam Karet（橡胶时间）：印尼人对时间相对灵活，会议迟到 10-15 分钟比较常见，但作为中国人建议你准时。
  • Gotong Royong（互助精神）：团队协作文化，讲究互相帮助，不谈界限分明。
  • Rapat（会议）：印尼的会议通常先寒暄再进入正题，直接切入正题会被认为不礼貌。
  • 决策方式：倾向于通过集体讨论达成一致，而不是个人拍板。
  • 拒绝别人时通常很委婉，会用 "Nanti dulu ya"（稍后再说）或 "Kita lihat nanti"（再看看），不要追问。
🍜 饮食文化▼
  • 印尼人吃饭用手抓（右手），尤其是吃传统食物。如果不习惯可以要勺子 "Minta sendok, ya"。
  • Sambal 是灵魂：几乎每顿饭都有辣椒酱。如果你不能吃辣，记得说 "Tidak pedas"。
  • 印尼是全球最大穆斯林国家，大部分食物是 Halal（清真）的，不要带猪肉制品到办公室。
  • 斋月（Ramadhan）期间，穆斯林从日出到日落不进食不喝水，斋月期间白天最好不要在同事面前吃东西喝水。
  • 受邀去印尼人家做客时，最好带一些糕点或水果作为礼物。
🕌 宗教与禁忌▼
  • 印尼约 87% 人口是穆斯林，此外有基督教、印度教（主要在巴厘岛）、佛教。
  • 进入寺庙或清真寺：必须穿过膝的裤子/裙子，女性要包头巾（通常有提供）。
  • 不要用左手递东西、握手或指人。
  • 不要摸别人的 头（包括小孩子），头被认为是神圣的部位。
  • 不要用食指指人/指东西，用大拇指或右手示意。
  • 不要公开批评宗教、政治敏感话题。
  • 狗在穆斯林文化中被视为不洁，注意场合。
🗣️ 沟通风格▼
  • 印尼人说话很委婉：很少直接说"不"，会用 "Maaf, belum"（抱歉还不行）、"Nanti"（待会儿）等方式。
  • 保持微笑和温和的语气非常重要，大声说话被认为是粗鲁的。
  • 在公共场合 尽量不要表露负面情绪（生气、不耐烦），印尼人讲究 "menjaga muka"（给人留面子）。
  • 批评最好在私下场合委婉地表达，先肯定再指出问题。
  • 关于 Small talk：聊天气、家庭、美食是拉近关系的好方法。
🏠 日常生活贴士▼
  • 交通：雅加达堵车严重（Macet），建议用 Gojek/Grab 摩托车出行，比汽车快很多。
  • App 必备：Gojek / Grab（打车外卖）、WhatsApp（工作沟通，印尼不用微信）、Tokopedia / Shopee（网购）。
  • 气候：热带气候，常年 25-33°C，分雨季（11月-3月）和旱季（4月-10月）。出门随身带伞。
  • 小费：部分餐厅账单已含服务费（service charge 5-10%），不需要额外给小费。
  • 电源：印尼使用两孔圆脚插座（欧标 Type C/F），需要带转换插头。
  • 语言态度：印尼人非常乐于看到外国人学习印尼语，即使你说得不标准，他们也会热情鼓励你。
