📐 基本句型

S-P-O 结构，和中文一样

印尼语和中文一样是"主谓宾"语序。最大不同：印尼语没有"是"动词（现在时）。

Saya makan nasi.
我 吃 饭
Saya adalah guru.
我 是 老师（adalah用于名词前）
Dia sedang kerja.
他/她 正在 工作
🔄 常用词缀

me- 主动动词前缀

表示"做某动作"，变体有 men-, mem-, meng-, meny-。

baca → membaca 读
Saya membaca buku.
tulis → menulis 写
Dia menulis laporan.
cari → mencari 找
Saya mencari kantor.

ber- 状态/进行 / ter- 意外/最

kerja → bekerja
Ayah bekerja di kantor.
besar → terbesar
Ini terbesar. 最大的
jatuh → terjatuh
Ponsel terjatuh. 摔了

di- 被动 / -an 名词 / pe- 人物

buka → dibuka
Pintu dibuka. 门被打开
makan → makanan
印尼 makanan enak! 食物好吃
ajar → pengajar
Dia pengajar. 他是老师
❌ 否定词三兄弟

Tidak（不）→ 否定动词/形容词

Saya tidak mau.
我不要

Bukan（不是）→ 否定名词

Saya bukan manajer.
我不是经理

Belum（还没）→ 未发生

Saya belum makan.
我还没吃

🤝 打招呼与社交▼
  • Salam：见面微笑着握手，要轻柔，然后右手触碰心口
  • 右手法则：递东西、接东西、握手、指物一律用右手
  • Apa Kabar万能开场，回答"Baik, Anda?"即可
  • 对长辈/上司说Bapak（先生）或Ibu（女士）
💼 职场文化▼
  • 层级观念强，对上级用敬称Bapak/Ibu
  • Jam Karet（橡胶时间）：时间较灵活，但你最好准时
  • Gotong Royong：团队互相帮助的文化
  • 会议先寒暄再切入正题
  • 拒绝时委婉："Nanti dulu ya"（稍后再说）
🍜 饮食文化▼
  • 用手抓饭吃（右手），不习惯说"Minta sendok"要勺子
  • Sambal每餐必备，不能吃辣说"Tidak pedas"
  • 大部分食物Halal（清真），不带猪肉到办公室
  • 斋月期间白天不在同事面前吃喝
🕌 宗教与禁忌▼
  • 87%人口是穆斯林，另有基督教和印度教（巴厘岛）
  • 进入寺庙必须穿过膝裤/裙
  • 不用左手递物、握手、指人
  • 不要摸别人的头（包括小孩）
  • 不用食指指人，用大拇指或右手示意
🗣️ 沟通风格▼
  • 说话委婉，很少直接说"不"
  • 保持微笑，大声说话是粗鲁的
  • 讲究menjaga muka（给人留面子），不当面批评
🏠 日常生活▼
  • Macet（堵车）是日常，用Gojek/Grab摩托更快
  • 用WhatsApp工作沟通，不用微信
  • 热带气候，11-3月雨季，随身带伞
  • 欧标两孔圆脚插头（Type C/F），带转换器
