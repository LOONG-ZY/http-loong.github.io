📐 基本句型

S-P-O 结构

和中文一样主谓宾。不同：现在时没有"是"动词。

Saya makan nasi.
我吃饭
Saya adalah guru.
我是老师
🔄 词缀

me-(主动) ber-(状态) ter-(意外/最) di-(被动) -an(名词) pe-(人物)

baca→membaca(读) / kerja→bekerja(工作) / besar→terbesar(最大) / buka→dibuka(被打开) / makan→makanan(食物) / ajar→pengajar(教师)
❌ 否定词 / ❓ 疑问词
Tidak(不) / Bukan(不是) / Belum(还没)
Saya tidak mau / Saya bukan bos / Saya belum makan
Apa(什么) Siapa(谁) Di mana(在哪) Kapan(何时) Berapa(多少) Kenapa(为什么)
👤 所有格 / 🔗 Yang / ⏰ 时间
-ku(我的) -mu(你的) -nya(他/她的) — bukuku(我的书)
Yang = 的 — Buku yang bagus(好书)
Sudah(已经) Sedang(正在) Pernah(曾经) Akan(将要)
Bisa(能) Mau(想) Harus(必须) Boleh(可以)
